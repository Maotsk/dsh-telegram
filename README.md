# 🤖 dsh-telegram

**Пульт управления сессиями [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) из Telegram — агент всегда под рукой.**

Список сессий, привязка, отправка промптов, живой стриминг ответов, ответы на вопросы
агента одним нажатием, остановка и переключение сессий — через тот же канал, которым
пользуется веб-интерфейс, из любого чата, который вы разрешите.

## ✨ Возможности

- **Полноценная консоль сессий** — `/attach` привязывает сессию, `/status` показывает её
  состояние, обычный текст уходит промптом, ответы стримятся в одно сообщение.
- **Живой стриминг** — вывод агента правится на месте в одном сообщении по ходу хода
  (`💭 Think` / `🔧 tool` построчно), в конце — HTML и футер с расходом токенов.
- **Вопросы агента кнопками** — когда агент вызывает `ask_user_question`, в чат приходит
  инлайн-клавиатура вместо простыни текста: ответ одним нажатием, отмена рядом;
  и Telegram, и веб-интерфейс видят один и тот же вопрос — кто ответил первым, тот и выиграл.
- **Одно-нажатие** — ответные клавиатуры несут `/create` `/archive` `/attach` и
  `/stop` `/close`; списки сессий и проектов рисуются инлайн-кнопками с полными названиями.
- **Русский интерфейс** — все сообщения, кнопки и меню `/` переведены (см. «Язык и клавиатура»).
- **Фото и картинки-документы** — отправьте боту фотографию (с подписью-вопросом или без)
  или PNG/JPEG/WebP/GIF файлом: агенту уйдёт картинка плюс текст. Фото **без подписи**
  по умолчанию агента не запускает: бот отвечает «Фото получено. Отправьте вопрос…»,
  держит картинку и отправляет её вместе со следующим сообщением (см. «Фото»).
- **Настройки в веб-интерфейсе** — токен, белый список чатов, прокси, язык, поведение
  клавиатуры и режим «фото без подписи» правятся на странице плагина и применяются
  без перезапуска.
- **Безопасно по умолчанию** — отвечает только чатам из `allowChatIds`, остальным бот
  отказывает, не раскрывая ничего о сессиях. Входящих портов плагин не открывает:
  только исходящий long-polling Telegram (при необходимости через прокси).

## 🚀 Установка

Нужен **DSH 0.2.x** (проверено на 0.2.0-rc.2) и доступ в интернет к GitHub —
репозиторий публичный, ключи не нужны.

**Способ 1 — через веб-интерфейс (файлы править не нужно):**

1. **Настройки → Плагины → установить плагин** и указать спецификацию пакета:

   ```
   github:Maotsk/dsh-telegram
   ```

2. Перезапустить приложение DSH и обновить страницу жёстко (**Ctrl+F5**), чтобы
   подтянулась карточка настроек.
3. Открыть **Настройки → Плагины → Telegram** и заполнить: токен от
   [@BotFather](https://t.me/BotFather), свой `chat id` в «Разрешённые чаты»,
   при необходимости HTTP-прокси. Сохранение применяется сразу, без перезапуска.

**Способ 2 — из командной строки** (на хосте, где стоит DSH):

```bash
dsh plugin --profile web add github:Maotsk/dsh-telegram
```

после чего перезапустить DSH. Строку бандла `@maotsk/dsh-host-telegram`
менеджер плагинов добавляет в профиль сам; если её не окажется в
`dsh.profile.bundles` (`$DSH_HOME/profiles/web/package.json`) — допишите вручную.

**Токен** можно либо ввести в карточке настроек (хранится в настройках профиля),
либо положить в `$DSH_HOME/.env` — файл с правами 600:

```bash
echo 'TELEGRAM_BOT_TOKEN=123456:AA...' >> "$DSH_HOME/.env"
chmod 600 "$DSH_HOME/.env"
```

**Проверка:** в логе DSH появятся строки `telegram: configuring bot for N allowed chat ids`
и `telegram: bot @<имя> listening`; в Telegram бот отвечает на `/start`, а `/attach`
показывает ваши сессии и проекты. Перезапуск нужен только при обновлении самого
пакета плагина — настройки применяются на лету.

### Переход с 0.1.0-rc.x (старое имя пакета)

До версии 0.2.0 плагин устанавливался под именем апстрима
`@deepseek-ai/dsh-host-telegram`. Если он уже стоит, поменяйте в профиле
(`$DSH_HOME/profiles/<профиль>/`) три места:

- ключ зависимости в `package.json`:
  `"@maotsk/dsh-host-telegram": "github:Maotsk/dsh-telegram#v0.2.0"`;
- строку в списке `dsh.profile.bundles` там же — на `@maotsk/dsh-host-telegram`;
- `name:` в строке плагина в `cordis.patch.yml` — на `@maotsk/dsh-host-telegram`.

Затем удалите старую копию и поставьте новую:

```bash
rm -rf "$DSH_HOME/profiles/<профиль>/node_modules/@deepseek-ai/dsh-host-telegram"
dsh plugin --profile <профиль> install
```

После перезапуска DSH и жёсткого обновления страницы всё на месте: id строки
(`telegram`) и сохранённые настройки — токен, чаты, прокси, язык, клавиатура —
переносятся автоматически, потому что они хранятся по id, а не по имени пакета.

## ⚙️ Настройки

Страница плагина: **Настройки → Плагины → `telegram`**. Поля:

| Поле | Что делает |
| --- | --- |
| Токен бота | Токен от [@BotFather](https://t.me/BotFather). Секретное поле: показывается как заданное, но не раскрывается. Пустое поле при сохранении **не затирает** уже заданный токен |
| Разрешённые чаты | Список `chat id`, которым бот отвечает. Пустой список — бот отказывает всем (свой id бот подскажет в ответе на первое сообщение) |
| HTTP-прокси | Прокси для Telegram, **только HTTP CONNECT** (например `http://user:pass@host:1080`). SOCKS5 не поддерживается. Пусто — берутся `ALL_PROXY`/`HTTPS_PROXY`, иначе прямое подключение |
| Язык интерфейса | `ru` (по умолчанию) или `zh` |
| Нижняя клавиатура | `dismissible` — сворачивается кнопкой Telegram (по умолчанию); `off` — не показывать совсем; `persistent` — закреплена всегда |
| Фото без подписи | `prompt` — ждать вопрос пользователя (по умолчанию); `run` — сразу отправить фото агенту с пометкой `[Пользователь прислал фото]`. Подпись к фото запускает ответ сразу в любом режиме |

Правки применяются на лету: плагин пересобирает сессию бота (токен, белый список,
прокси, язык, клавиатура, режим фото) без перезапуска DSH.

## 🖼️ Фото

Что происходит, когда вы отправляете боту картинку:

- **С подписью** — подпись считается вопросом, и картинка с текстом уходят агенту сразу.
- **Без подписи** — по умолчанию (`prompt`) бот ничего не запускает: отвечает
  «📷 Фото получено. Отправьте вопрос…», запоминает картинку и при отправке
  следующего текста прикладывает её к промпту. Так фото не тратит ход агента, пока
  вы не напишете, что с ним делать. Если хочется обратного — переключите поле
  «Фото без подписи» в `run`: картинка уйдёт сразу, а вместо вопроса будет пометка
  `[Пользователь прислал фото]`.
- **Несколько фото сразу (альбом)** — все картинки уходят одним промптом, подсказка
  «отправьте вопрос» приходит один раз.
- **Картинки-документы** — PNG, JPEG, WebP и GIF, отправленные файлом, работают так же.
  Другие документы (PDF и т. п.) бот отклоняет: «формат не поддерживается».
- **Ограничения Telegram** — бот может скачать файл не больше 20 МБ; слишком большие
  картинки бот отклоняет с пояснением. Файл качается через тот же прокси, что и все
  остальные обращения к Telegram.

## 💬 Команды

| Команда | Что делает |
| --- | --- |
| `/start` | Справка и список команд |
| `/keyboard` | Показать/обновить нижнюю клавиатуру с частыми действиями |
| `/attach` | Выбрать сессию и привязать её (`/attach <номер\|id\|none\|arc>`) |
| `/status` | Подробности привязанной сессии |
| `/create` | Создать сессию: `/new` (в проекте, вне проекта или по пути) либо `/fork` (форк текущей) |
| `/archive` | Архивировать сессию |
| `/rename` | Переименовать сессию |
| `/model` | Каталог моделей и выбор глобальной модели по умолчанию |
| `/preset` | Сменить пресет агента (доступно до первого хода в сессии) |
| `/stop` | Прервать текущий ход |
| `/close` | Убрать нижнюю клавиатуру |

Списки сессий, проектов, моделей и пресетов приходят кнопками — можно работать вообще
без набора команд; всё то же доступно и текстом.

## 🌍 Язык и клавиатура

Апстрим написан с китайскими строками и без i18n. В форке перевод сделан на границе
вывода: словарь `src/locale-ru.ts` (249 фраз + числовые правила с согласованием:
«5 минут назад», «3 сессии») применяется к исходящим сообщениям и подписям кнопок.
Служебные данные не переводятся, поэтому нажатия кнопок и маршрутизация команд
работают как раньше; `locale: zh` возвращает исходное поведение.

Названия проектов и пресетов в кнопках больше не обрезаются до 6–8 символов —
подпись заполняется до лимита Telegram (60 символов). Нижнюю клавиатуру можно свернуть
штатной кнопкой Telegram, а режим `off` убирает её полностью.

## 🧩 Отличия от апстрима

- Хост-слой: вместо отсутствующего `apiProxy` — in-process сервисы DSH 0.2.x
  (`sessionController`, `workspaceRegistry`, `agentDefaultModel`, `agentPresets`,
  `settingsController`, `userQuestions`).
- Русская локализация, страница настроек, режимы клавиатуры, полные подписи кнопок.
- Приём фото и картинок-документов: image-части промпта плюс режим «фото без подписи
  ждёт вопрос» (по умолчанию), как в `dsh-messenger-gateway`.
- Отмена вопроса (`🚫`) в 0.2.x выражается «пропуском»: отдельного `cancel`
  у сервиса вопросов нет.

Подробности и внутренние детали — в [FORK.md](FORK.md).
