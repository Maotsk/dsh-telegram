# Changelog

Форк [Kevin66Z0/dsh-telegram](https://github.com/Kevin66Z0/dsh-telegram), портированный
на **DSH 0.2.x**. Версии ниже — версии пакета `@maotsk/dsh-host-telegram` в этом
форке; апстримный тег `v1.0.0` относится к их самому первому коммиту и к этой линии
отношения не имеет.

## 0.2.0 — 2026-10-14

Первый обычный (не pre-release) релиз линии форка.

- **Пакет переименован:** `@maotsk/dsh-host-telegram` (было `@deepseek-ai/dsh-host-telegram` — имя апстрима). Вместе с именем обновлены строка бандла в `cordis.patch.yml`, id клиентского модуля, имя в invariant-компаньоне, документация и скрипт установки. При обновлении уже установленного плагина нужно поменять спецификацию в профиле (ключ зависимости, список `dsh.profile.bundles` и `name:` в строке плагина); id строки (`telegram`) и сохранённые настройки при этом не меняются.
- **Линия версий:** `0.2.x` соответствует поколению DSH 0.2.x; при смене поколения DSH — `0.3.x`.
- Тег `v1.0.0` в репозитории — апстримный (первый коммит автора), к этой линии отношения не имеет.

## 0.1.0-rc.15 — 2026-10-14

- Репозиторий стал самостоятельным: `tsconfig.json` больше не ссылается на корень
  монорепозитория апстрима, добавлены devDependencies (`vitest`, `@types/node` и
  пакеты DSH 0.2.x), заработал `npm test` — **404 теста**, все зелёные
  (в апстримных тестах импорт удалённого `dsh-host-apiproxy` переключён на локальный шим).
- Проверки перенесены в репозиторий: `npm run check:client` (карточка настроек в вебе —
  одна регистрация слота, summary/полный вид) и `npm run check:locale` (полнота перевода:
  148 строк, включая варианты с подставленными значениями), плюс `npm run check` = обе
  проверки + сборка.
- Кнопки: бюджет подписи учитывает многоточие, поэтому подпись гарантированно укладывается
  в лимит Telegram.

## 0.1.0-rc.14 — 2026-10-14

- Русский README стал основным (`README.md` показывается на GitHub по умолчанию),
  английский вынесен в `README.en.md` и переписан под 0.2.x, в китайском — баннер со
  ссылками; на всех трёх страницах переключатели языков.
- `package.json` и `README.i18n.yaml` приведены в соответствие.

## 0.1.0-rc.13 — 2026-10-14

- Карточка настроек: регистрируется только слот `plugins.item` (слот `plugins.row.config`
  давал вторую копию формы), учитывает режим `summary` — в списке плагинов одна строка
  описания, на странице — сразу все поля.

## 0.1.0-rc.10 … 0.1.0-rc.12 — 2026-10-14

- Карточка настроек в веб-интерфейсе: клиентская половина (`lib/client.js`) + маршрут
  `GET/PUT /dsh-host-telegram/config`; в карточке токен, разрешённые чаты, прокси, язык и
  режим клавиатуры. Правки применяются без перезапуска.
- Токен — секретное поле: в браузер не отдаётся, пустое поле не затирает сохранённый токен.

## 0.1.0-rc.8 … 0.1.0-rc.9 — 2026-10-14

- Русский интерфейс: словарь `src/locale-ru.ts` (249 пар + числовые правила с согласованием)
  применяется на границе вывода; `locale: zh` возвращает исходный язык.
- Настройки через сервис `settings` (поля `.volatile()`), нижняя клавиатура
  (`dismissible`/`off`/`persistent`), подписи кнопок заполняются до лимита Telegram,
  строки списков расширены с 48 до 80 символов.
- Русский README.

## 0.1.0-rc.7 — 2026-10-14

- История сессии читается по курсору из проекций (`asOfSeq`), с резервом через
  `sessionController.inspect`.
- Выбор пресета работает и на «холодной» сессии — через `sessionController.resolveAgent`.
- Коды ошибок хоста приводятся к старому формату (`agent-preset/locked` → `agent-preset-locked`).

## 0.1.0-rc.6 — 2026-10-14

- **Порт на DSH 0.2.x.** Сервис `apiProxy` поколения 0.0.x заменён адаптером к in-process
  сервисам 0.2.x (`sessionController`, `workspaceRegistry`, `agentDefaultModel`,
  `agentPresets`, `settingsController`, `userQuestions`), типы старого контракта объявлены
  локально (`src/apiproxy-shim.ts`), вопросы агента проброшены из waterfall
  `user-questions/request`.
